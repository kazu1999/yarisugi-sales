# Yarisugi Sales - 営業支援システム

## 概要
Yarisugi Salesは、営業担当者の業務効率化を目的とした包括的な営業支援システムです。顧客管理、提案書作成、知識管理、AIメール機能を統合し、営業活動を効率的にサポートします。

## 使用方法

### 会社プロフィール管理
1. 「基本情報入力」タブを選択
2. 会社の基本情報を入力・編集
3. 「提案書を追加」ボタンで新しい提案書を追加
4. 提案書の並び替えや編集・削除を実行

### 顧客管理
1. 「顧客管理」タブを選択
2. 「顧客を追加」ボタンで新しい顧客を登録
3. 顧客一覧から顧客を選択して詳細を確認
4. 顧客情報の編集・削除を実行

### 知識管理
1. 「知識管理」タブを選択
2. 「知識を追加」ボタンで新しい知識を登録
3. カテゴリを選択して知識を分類
4. 知識の編集・削除を実行

### RAG検索
1. 「RAG検索」タブを選択
2. 検索したい内容を入力
3. 関連する知識ベースの情報が表示される
4. AIによる回答を確認

### AI FAQ生成
1. 「AI FAQ生成」タブを選択
2. 「FAQを生成」ボタンをクリック
3. 知識ベースから自動的にFAQが生成される
4. 生成されたFAQを確認・編集

### 顧客レポート
1. 顧客詳細ページの「概要」タブを選択
2. 「レポート抽出」ボタンをクリック
3. 顧客分析レポートが生成される
4. 提案書最適化のための分析結果を確認

### AIメール機能
1. トップページの「AIメール」を選択
2. メール接続を選択（初回は接続設定が必要）
3. **🚀 高速化されたメール取得**: 並列処理により大幅に高速化されたメール一覧を確認
4. 顧客からのメールのみが表示される
5. メールをクリックして詳細を確認
6. **🤖 AI返信提案**: メール詳細画面で「AI返信提案」ボタンをクリック
7. FAQ情報を活用した高品質な返信提案を確認
8. 「返信」ボタンで返信画面を開き、AI提案を活用して返信を作成

### ファイル管理機能
1. 顧客詳細ページの「ファイル管理」タブを選択
2. **📄 ファイルアップロード**: 
   - 「ファイルを選択」でPDF・音声ファイルをアップロード
   - または「音声録音」でリアルタイム録音
3. **🎤 音声録音**:
   - 「録音開始」ボタンで録音開始
   - 「録音停止」で録音終了・自動アップロード
4. **🤖 AI処理**: アップロード後、自動的にAI要約が生成される
5. **❓ ファイル質問**: 
   - ファイル詳細画面の「質問」タブを選択
   - ファイル内容について質問を入力
   - AIがファイル内容を基に回答を生成
6. **📊 ファイル管理**: 一覧からファイルの詳細確認・削除が可能

## 環境設定

### 必要な環境変数
- `VITE_API_ENDPOINT`: API Gateway エンドポイント
- `VITE_COGNITO_USER_POOL_ID`: Cognito User Pool ID
- `VITE_COGNITO_CLIENT_ID`: Cognito Client ID
- `VITE_REGION`: AWS リージョン

### セットアップ手順
1. リポジトリをクローン
2. 依存関係をインストール: `npm install`
3. 環境変数を設定
4. 開発サーバーを起動: `npm run dev`
