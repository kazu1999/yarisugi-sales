# Yarisugi Sales Management System

## 概要
Yarisugi Sales Management Systemは、営業活動を効率化し、顧客管理からナレッジベースまで統合的に管理できるWebアプリケーションです。AIを活用した顧客分析と営業戦略提案機能により、営業担当者の生産性を大幅に向上させます。

## 主要機能

### 🏢 顧客管理機能
- 顧客情報の登録・編集・削除
- 顧客ステータス管理（新規、商談中、成約、失注）
- 業界別・地域別フィルタリング
- 顧客詳細ページ（営業アクション、LINE管理など）
- **AI顧客レポート生成** - 顧客のWebサイト分析を含む詳細な営業戦略提案

### 📧 AIメール機能 ✅ 最新版
- **メール接続管理**: IMAP接続によるメールアカウント管理
- **顧客フィルタリング**: 顧客テーブルに登録されている顧客からのメールのみ表示
- **メール一覧表示**: 最新30件のメールを高速表示（パフォーマンス最適化）
- **メール詳細表示**: 個別メールの内容・添付ファイル表示
- **メール返信機能**: SMTP送信による返信機能
- **🤖 AI返信提案機能**: FAQ情報を活用したAIによる返信提案生成
- **複数アカウント対応**: 複数のメールアカウントを管理
- **セキュア接続**: SSL/TLS対応の安全なメール接続

### 📚 ナレッジベース機能
- ナレッジの登録・管理
- PDFファイルの自動アップロード・処理
- RAG検索による高精度な情報検索
- ベクトル化による高速検索

### 🤖 AI支援機能
- RAG検索による質問応答
- FAQ自動生成
- 営業文書の自動生成
- 顧客対応の自動化
- **顧客レポート自動生成** - Webサイト分析を含む包括的な顧客分析
- **AIメール機能** - IMAP接続によるメール取得・管理・分析
- **AI返信提案** - FAQ情報を活用した高品質なメール返信提案

### 🏢 基本情報管理機能
- 自社情報の管理（会社名、自己紹介文、サービス構成、実績）
- 提案内容の動的管理（追加・編集・削除）
- 提案内容の順序管理
- 提案資料URL管理

### 📊 営業プロセス管理
- 営業プロセスの可視化
- 進捗管理
- テンプレート機能
- 承認フロー

## セットアップ

### 前提条件
- Node.js 18以上
- AWS CLI
- Terraform

### インストール
```bash
# リポジトリのクローン
git clone <repository-url>
cd yarisugi-sales

# 依存関係のインストール
npm install

# 環境変数の設定
cp .env.example .env
# .envファイルを編集して必要な値を設定

# 開発サーバーの起動
npm run dev
```

### AWS設定
```bash
# AWS認証情報の設定
aws configure

# Terraformの初期化と適用
cd backend/terraform
terraform init
terraform plan
terraform apply
```

## 使用方法

### AIメール機能 ✅ 最新版
1. サイドバーから「AIメール」を選択
2. 「メール接続」ボタンでメールアカウントを追加
   - メールアドレス、パスワード、IMAPサーバー、ポートを入力
   - Gmailの場合は「imap.gmail.com:993」を使用
3. 「メール一覧表示」ボタンで接続済みアカウントのメールを表示
   - **顧客テーブルに登録されている顧客からのメールのみ表示**
   - フィルタリング情報が青いインジケーターで表示
4. メールをクリックして詳細内容を確認
5. **「🤖 AI返信提案」ボタンをクリックしてAIによる返信を生成**
   - FAQ情報を活用した高品質な返信が生成されます
   - 生成された返信は返信画面に自動的に反映されます
6. 「返信」ボタンでメール返信機能を使用
7. 複数のメールアカウントを管理可能

### AI顧客レポート生成
1. 顧客詳細ページの「概要」タブに移動
2. 「レポート抽出」ボタンをクリック
3. AIが自動的に顧客のWebサイトを分析
4. 包括的な顧客分析レポートを生成
5. レポートのダウンロードも可能

### 基本情報管理
1. サイドバーから「基本情報入力」を選択
2. 自社情報を入力・保存
3. 「提案内容を追加」ボタンで新しい提案を追加
4. 提案内容の編集・削除・順序変更

### 顧客管理
1. サイドバーから「顧客一覧」を選択
2. 「新規登録」ボタンで顧客を追加
3. 顧客名をクリックして詳細ページに移動
4. 各タブで営業活動を管理

### ナレッジベース
1. サイドバーから「ナレッジDB」を選択
2. 「ナレッジを追加」で新しいナレッジを登録
3. PDFファイルをアップロードして自動処理
4. 「ナレッジ検索」でAI検索を実行

## API仕様

### メール管理API ✅ 最新版
- `POST /email/test-connection` - メール接続テスト
- `POST /email/save-connection` - メール接続保存
- `GET /email/connections` - メール接続一覧取得
- `DELETE /email/connections/{connectionId}` - メール接続削除
- `GET /email/messages` - メール一覧取得（顧客フィルタリング対応）
- `GET /email/messages/{messageId}` - メール詳細取得
- `POST /email/send` - メール送信（返信機能）
- `POST /email/ai-reply` - AI返信提案生成（FAQ活用）

### 顧客レポート生成API
- `POST /customer-report` - AI顧客レポート生成（Webサイト分析含む）

### 基本情報管理API
- `GET /company-profile` - 基本情報取得
- `PUT /company-profile` - 基本情報更新
- `GET /company-profile/proposals` - 提案内容一覧取得
- `POST /company-profile/proposals` - 提案内容追加
- `PUT /company-profile/proposals/{id}` - 提案内容更新
- `DELETE /company-profile/proposals/{id}` - 提案内容削除

### 顧客管理API
- `GET /customers` - 顧客一覧取得
- `POST /customers` - 顧客登録
- `GET /customers/{id}` - 顧客詳細取得
- `PUT /customers/{id}` - 顧客情報更新
- `DELETE /customers/{id}` - 顧客削除

### ナレッジ管理API
- `GET /knowledge` - ナレッジ一覧取得
- `POST /knowledge` - ナレッジ登録
- `GET /knowledge/{id}` - ナレッジ詳細取得
- `DELETE /knowledge/{id}` - ナレッジ削除

### RAG検索API
- `POST /rag-search` - AI検索実行

## 開発

### ディレクトリ構造
```
src/
├── components/          # Reactコンポーネント
│   ├── common/         # 共通コンポーネント
│   ├── customer/       # 顧客管理コンポーネント
│   ├── knowledge/      # ナレッジ管理コンポーネント
│   ├── company/        # 基本情報管理コンポーネント
│   └── modals/         # モーダルコンポーネント
│       ├── EmailConnectionModal.jsx    # メール接続モーダル
│       ├── EmailListModal.jsx          # メール一覧モーダル
│       ├── EmailDetailModal.jsx        # メール詳細モーダル（AI返信提案対応） ✅ 更新
│       └── EmailReplyModal.jsx         # メール返信モーダル
├── hooks/              # カスタムフック
│   └── useEmailConnection.js           # メール接続管理フック
├── pages/              # ページコンポーネント
├── utils/              # ユーティリティ関数
└── App.jsx             # メインアプリケーション

backend/
├── lambda_functions/   # Lambda関数
│   ├── customer_report/ # 顧客レポート生成
│   ├── company_profile/ # 基本情報管理
│   ├── email_manager/   # メール接続管理
│   ├── email_fetcher/   # メール取得・詳細（顧客フィルタリング対応）
│   ├── email_sender/    # メール送信（返信機能）
│   ├── email_ai_reply/  # AI返信提案生成（FAQ活用） ✅ 新規追加
│   ├── rag_search/     # RAG検索
│   └── knowledge_manager/ # ナレッジ管理
├── terraform/          # Terraform設定
└── common/             # 共通ライブラリ
```
