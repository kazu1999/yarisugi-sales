# Yarisugi Sales - 営業支援システム

## 概要
Yarisugi Salesは、営業担当者の業務効率化を目的とした包括的な営業支援システムです。顧客管理、提案書作成、知識管理、AIメール機能を統合し、営業活動を効率的にサポートします。

## 使用方法

### 会社プロフィール管理
1. 「基本情報入力」タブを選択
2. 会社の基本情報を入力・編集
3. 「提案書を追加」ボタンで新しい提案書を追加
4. 提案書の並び替えや編集・削除を実行

### 顧客管理
1. 「顧客管理」タブを選択
2. 「顧客を追加」ボタンで新しい顧客を登録
3. 顧客一覧から顧客を選択して詳細を確認
4. 顧客情報の編集・削除を実行

### 知識管理
1. 「知識管理」タブを選択
2. 「知識を追加」ボタンで新しい知識を登録
3. カテゴリを選択して知識を分類
4. 知識の編集・削除を実行

### RAG検索
1. 「RAG検索」タブを選択
2. 検索したい内容を入力
3. 関連する知識ベースの情報が表示される
4. AIによる回答を確認

### AI FAQ生成
1. 「AI FAQ生成」タブを選択
2. 「FAQを生成」ボタンをクリック
3. 知識ベースから自動的にFAQが生成される
4. 生成されたFAQを確認・編集

### 顧客レポート
1. 顧客詳細ページの「概要」タブを選択
2. 「レポート抽出」ボタンをクリック
3. 顧客分析レポートが生成される
4. 提案書最適化のための分析結果を確認

### AIメール機能
1. トップページの「AIメール」を選択
2. メール接続を選択（初回は接続設定が必要）
3. **🚀 高速化されたメール取得**: 並列処理により大幅に高速化されたメール一覧を確認
4. 顧客からのメールのみが表示される
5. メールをクリックして詳細を確認
6. **🤖 AI返信提案**: メール詳細画面で「AI返信提案」ボタンをクリック
   - **FAQベースの返信生成**: データベースに保存されたFAQの内容を元に、AIが適切な返信を自動生成
   - **営業文脈の考慮**: 営業担当者の文脈や顧客の状況を考慮した返信提案
   - **丁寧な返信スタイル**: 200-400文字程度の丁寧で親しみやすい返信文を生成
   - **リアルタイム生成**: メール内容を分析して即座に返信提案を表示
7. FAQ情報を活用した高品質な返信提案を確認
8. 「返信」ボタンで返信画面を開き、AI提案を活用して返信を作成

#### AI返信提案の仕組み
- **FAQ活用**: システムに登録されたFAQ（よくある質問と回答）の内容を参考に、AIが返信文を生成
- **文脈理解**: 顧客からのメール内容を分析し、適切な回答を提案
- **営業最適化**: 営業担当者向けに最適化されたプロンプトを使用し、ビジネスに適した返信を生成
- **品質保証**: OpenAI GPT-4o-miniを使用した高品質な自然言語処理

### ファイル管理機能
1. 顧客詳細ページの「ファイル管理」タブを選択
2. **📄 ファイルアップロード**: 
   - 「ファイルを選択」でPDF・音声ファイルをアップロード
   - または「音声録音」でリアルタイム録音
3. **🎤 音声録音**:
   - 「録音開始」ボタンで録音開始
   - 「録音停止」で録音終了・自動アップロード
4. **🤖 AI処理**: アップロード後、自動的にAI要約が生成される
5. **❓ ファイル質問**: 
   - ファイル詳細画面の「質問」タブを選択
   - ファイル内容について質問を入力
   - AIがファイル内容を基に回答を生成
6. **📊 ファイル管理**: 一覧からファイルの詳細確認・削除が可能

### 機能追加要望フォーム
1. トップページの「機能追加要望フォーム」を選択
2. **📝 要望入力**:
   - 「どんな機能が欲しいですか？」に機能の詳細を入力
   - 例：FAQをチャット形式で表示したい、PDFから自動でナレッジ化したい など
3. **⭐ 緊急度選択**:
   - 「すぐ欲しい！」: 優先度の高い機能要望
   - 「そのうち欲しい」: 中期的な機能要望
   - 「アイデアとして共有」: 将来的なアイデア
4. **📎 添付ファイル**（任意）:
   - 必要に応じて関連ファイルを添付
5. **📤 送信**: 「ご要望を送信する」ボタンで要望を送信
6. **✅ 確認**: 送信完了メッセージで要望が正常に保存されたことを確認

### 管理者画面（管理者専用）
1. **🔐 管理者画面へのアクセス**:
   - 機能追加要望フォームのタブを5回連続でクリック
   - 管理者画面が表示される
2. **📋 要望一覧の確認**:
   - 送信されたすべての要望が一覧表示される
   - 緊急度、ステータス、送信者、送信日時が表示される
3. **🔍 フィルタリング・検索**:
   - 緊急度フィルタ: すぐ欲しい/そのうち欲しい/アイデアとして共有
   - ステータスフィルタ: 送信済み/対応中/完了/却下
   - 検索機能: 要望内容やメールアドレスで検索
4. **⚙️ ステータス更新**:
   - 各要望のドロップダウンでステータスを変更
   - 送信済み → 対応中 → 完了/却下の流れで管理
5. **📄 ページネーション**:
   - 10件ずつ表示され、大量の要望も効率的に管理
   - 前へ/次へボタンでページ移動
6. **🔄 更新**: 更新ボタンで最新の要望情報を取得

## 環境設定

### 必要な環境変数
- `VITE_API_ENDPOINT`: API Gateway エンドポイント
- `VITE_COGNITO_USER_POOL_ID`: Cognito User Pool ID
- `VITE_COGNITO_CLIENT_ID`: Cognito Client ID
- `VITE_REGION`: AWS リージョン

### セットアップ手順
1. リポジトリをクローン
2. 依存関係をインストール: `npm install`
3. 環境変数を設定
4. 開発サーバーを起動: `npm run dev`
